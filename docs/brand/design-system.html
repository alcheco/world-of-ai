01 · Marca

Emblema y logotipo

El emblema es un medallón de oro con alas cortas y una gema arcana. Dentro hay un globo de diálogo con el prompt >_: conversar y programar en el mismo gesto. El oro en relieve y el azul arcano vienen del lenguaje visual de los MMO de fantasía, sin copiar ningún logo existente.

Emblema a color. Icono del addon, CurseForge y avatar.
64 · 32 · 16 px. Por debajo de 32 px se exporta sin alas ni remaches para el botón del minimapa.

05 · Tokens

Theme.lua

Los mismos valores como tabla del addon, para dejar de repetir números sueltos en UI.lua.

local _, ns = ...
ns.Theme = {
  arcane     = { 0.56, 0.83, 1.00 },  -- marca
  gold       = { 1.00, 0.82, 0.00 },  -- encabezados
  metal      = { 0.79, 0.64, 0.29 },
  bronze     = { 0.42, 0.32, 0.15 },  -- borde de ventana
  crimson    = { 0.43, 0.09, 0.09 },
  panel      = { 0.06, 0.06, 0.08, 0.95 },
  panel2     = { 0.10, 0.10, 0.13 },
  hover      = { 0.20, 0.20, 0.28 },
  select     = { 0.18, 0.26, 0.38 },
  selectEdge = { 0.40, 0.60, 0.90 },
  text       = { 0.88, 0.88, 0.88 },
  code       = { 0.75, 0.90, 0.75 },
  ok         = { 0.20, 1.00, 0.60 },
  err        = { 1.00, 0.33, 0.33 },
  hex = { arcane = "8fd3ff", gold = "ffd100", ok = "33ff99", err = "ff5555", muted = "999999" },
}
function ns.Theme:Wrap(key, text) return "|cff" .. self.hex[key] .. text .. "|r" end
06 · Reglas

Uso

Sí

  • Oro para jerarquía (títulos, proyectos) y arcano para la marca y lo interactivo.
  • Bordes de ventana en bronce con un filo negro, como los marcos del cliente.
  • Estado siempre en dos sitios: franja de color y texto.
  • Emblema sin alas por debajo de 32 px.

No

  • Usar logotipos, tipografías ni arte de Blizzard en material fuera del juego.
  • Más de un botón carmesí por vista.
  • Texto gris sobre carmesí o arcano sobre oro: no se lee.
  • Degradados en el texto dentro del juego; el relieve es solo del logotipo.
